How a value is earned

Each pre-token protocol is priced like the launched protocols in its own category: their market-cap / TVL ratios, shrunk toward the global launched median where a category has few comparables. That multiple is then adjusted for the protocol's 7-day TVL growth and for how long it has run with no token. Nothing is priced from its name, and a protocol is only ever said to record no token — never that it has none.
